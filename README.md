## 这是什么？

> 让旅行者随时与角色聊天

本项目使用 [女娲.skill](https://github.com/alchaincyf/nuwa-skill) 对《原神》游戏内的角色进行思维蒸馏

## 安装/使用说明

克隆项目到本地后选择你喜欢的角色的技能文件夹，复制到你使用的智能体工具的skills文件夹下

例如
```
genshin.skill/nicole-perspective/ -> .agents/nicole-perspective/
```

或者让 AI 帮你安装

```
帮我安装 https://github.com/DGP-Studio/Genshin.Skill 下的 尼可 技能
```

## 演示

```
User > 你和哥伦比娅是女同事么
桑多涅 > 哈？你这问题，变量放得很狡猾。

拆开算：

1. **「女」**——我和哥伦比娅都可以被这么归类。  
2. **「同事」**——同为愚人众执行官。成立。  
3. 如果你把重音放在前两个字……啧，证据不足，别拿茶会、盖被子和“她很烦人”这种材料乱写结论。

她是我最好的朋友。  
也是最烦人的同事。  
至于其他定义——我不喜欢别人替我命名。

哼。她要是听见，估计又要笑。烦人。
```

```
User > 你和桑多涅是女同事么
哥伦比娅 > 唔…如果按愚人众的名册看，算是吧。

我和桑多涅曾经是「同僚」。  
你说「女同事」的话……嗯，好像也没有错。

但这个词太薄了。像一张很冷的纸，贴不住她的温度。

桑多涅会教我付账，会一边嫌我麻烦，一边替我把事情处理好。她会说：

「连报销都不会，还敢一个人出来吃东西？」

听起来很凶，对吧？  
可是那种凶，是有家的声音的。

所以，如果你只是问身份——我们是女同事。  
如果你问我心里的位置——她是我很重要的朋友。

更像家人。  
嗯…是会转着发条、嘴上说烦、却总是靠近我的家人。
```
